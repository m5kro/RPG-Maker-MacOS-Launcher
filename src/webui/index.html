RPG Maker Launcher

macOS Apple Silicon 専用 · NW.js / MKXP-Z / EasyRPG

使い方

MV / MZ: NW.js の版を選び、ゲームフォルダを選択して起動します。導入済みの版はオフラインでも利用できます。「公開版を取得」はネットワークから ARM 対応版の一覧を取得します。

XP / VX / VX Ace: Game.ini を含むフォルダを選びます。Downloads 外への移動を推奨します。2000 / 2003: RPG_RT ファイルを含むフォルダを選びます。必要な MKXP-Z / EasyRPG / RTP 等は内容を確認し、同意した場合のみダウンロードします。

Standalone は元ゲームを保全し、コピーを別の .app に書き出します。既存の出力は上書きしません。Windows では元の EXE を直接使用してください。

保護を無効にするとゲームの子プロセス起動・外部通信が許可されます。信頼できるゲームのみで使用してください。ゲーム・セーブのバックアップを推奨します。チート・英語版展開・Optimize は実行しません。

ゲームはランチャー終了後も動作を続けます。実行中は同じ管理フォルダの起動・取得・書き出し・削除がロックされます。詳細設定は保存してから起動してください。
